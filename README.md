# 💸 Финтрек

**Трекер личных финансов: доходы, расходы и наглядные графики. Работает офлайн, устанавливается на телефон как приложение.**

### ▶️ [Открыть приложение](https://mmmaksmog-commits.github.io/finance-tracker/)

При первом запуске показываются демо-данные за полгода. Их можно убрать одной кнопкой.

---

## Возможности

- Учёт доходов и расходов по категориям
- Сводка за месяц с анимированными цифрами и переключение месяцев
- Кольцевая диаграмма расходов по категориям
- Столбчатый график «доходы и расходы» за 6 месяцев
- Поиск и фильтры по операциям
- Удаление с возможностью отменить его
- Экспорт в CSV (открывается в Excel)
- Светлая и тёмная тема, включая системную
- **PWA**: работает без интернета через Service Worker
- Адаптивность: на ПК форма находится в боковой панели, на телефоне выезжает снизу

## Стек

- **JavaScript (ES-модули)**, HTML, CSS (Grid, custom properties, `color-mix`)
- [Chart.js](https://www.chartjs.org/) для графиков
- `localStorage` для хранения данных, Service Worker для офлайн-режима

## Структура

```
js/
├── store.js   # данные и вычисления (итоги, категории, история, CSV)
└── app.js     # интерфейс, графики, форма
sw.js          # офлайн-кэш
```

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/finance-tracker.git
cd finance-tracker
python3 -m http.server 8000
```
